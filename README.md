# MCA x Minecolonies Integration

An integration mod that bridges [Minecraft Comes Alive (MCA)](https://github.com/Luke100000/minecraft-comes-alive) and [Minecolonies](https://github.com/ldtteam/minecolonies), allowing MCA villagers to work within Minecolonies colonies.

## Features

- MCA villagers can be assigned to Minecolonies colony roles
- Seamless integration between both mod systems
- Compatible villager AI and behavior systems

## Requirements

- Minecraft (Forge/NeoForge)
- Minecraft Comes Alive (MCA)
- Minecolonies
